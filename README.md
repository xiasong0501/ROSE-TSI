# Trustworthy Spatial Intelligence Team

可信空间智能研究团队（TSI Team）网站，所属单位为南洋理工大学 ROSE Lab。默认中文，可切换英文。

## 维护内容

- `content.js`：成员资料、中英文研究方向、论文与链接。
- `styles.css`：字体、配色与响应式布局。
- `app.js`：语言切换和研究成果展开交互。
- `assets/`：成员照片、简历 PDF、NTU 标志与研究概念配图。

网站使用 HTML、CSS 和 JavaScript，无需安装依赖或构建。图片和简历均随站点托管，字体使用系统字体，无需 Google Fonts。论文和学术主页属于外部链接。

## GitHub Pages

仓库 Settings → Pages → Deploy from a branch → main → /(root)。
启用后地址：https://xiasong0501.github.io/ROSE-TSI/
向 main 推送修改后，GitHub Pages 自动重新发布。

论文作者行展示本团队参与成员，并非完整作者列表。在审投稿与预印本保留状态标记。
照片、简历和论文信息来自团队提供的材料。研究配图为概念插图。
